# Retail Sales Dashboard

An interactive sales analytics dashboard built for retail businesses 
to track KPIs, identify trends, and forecast future sales.

## Features
- Daily/weekly/monthly sales tracking
- Product performance analysis
- Customer segmentation
- 30-day sales forecasting with ML
- Automated report generation

## Tech Stack
- Python (Pandas, Scikit-learn, Matplotlib)
- Power BI / Plotly Dash
- SQL for data extraction

## Business Impact
- Reduces manual reporting time by 80%
- Provides real-time inventory alerts
- Forecasting accuracy: ~85%

## Use Cases
Retail stores, supermarkets, e-commerce businesses
